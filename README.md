# genArchSelect
Project exploring the genetic architecture of selection on single locus (sweeps) to multiple loci (polygenic) under a unified model. Primarily involves SLiM simulations and population genetic analysis of simulated sequence data.

# File directories

`QTL_finalModel_SURC` contain the code for the latest simulations used (as of december 2024)

`QTL_prototype` contain the code that was previously used to tweak and check various parameters of our simulations

`Rscripts` contain R scripts that are used to process the output files to obtain information about changes in Allele frequencies, Phenotype, Linkage Disequillibrium and more

`trialSims` contains code for certain models of polygenic traits and nucleotides based traits. Provided by Diptarup Nandi.
